# 高德官方公开榜单网页采集通道（2026-10-02验证）

## 结论

高德提供无需登录、服务端直接渲染的公开榜单页，可快速取得已上榜门店名单和 POI ID。深圳当前公开页覆盖 2025 高德状元榜·美食、烟火小店、极致甄选美食，共保存 23 个有效页面，包含 205 条榜单记录、166 个唯一 POI。

这些页面不是 2026 回头客榜，不能用来证明近180天回头客人数。它们可以作为独立的高德官方上榜证据，并为后续详情补全提供 POI ID。

## 榜单页面

- 全城：`https://www.amap.com/ranking/shenzhen/{food|shop|select-food}`
- 行政区：`https://www.amap.com/ranking/shenzhen/{food|shop}/{adcode}`
- 极致甄选当前只有全城、福田区、南山区页面返回有效榜单。

公开 HTML 可直接读取：

- 榜单名称、范围、页面内位置；
- 门店名和高德 POI ID；
- 页面原始指标（全年综合分或中高消费人群人数）；
- 标签、推荐文案；
- 高德图片引用地址。图片未取得转载许可，只能用于来源核验。

## 当前 POI 详情

在公开 `https://www.amap.com/place/{POIID}` 页面加载后，页面自身调用：

`https://amap-pc-ssr.amap.com/ssr/api/getPoiInfo?id={POIID}`

请求不含 API Key、登录参数或签名。2026-10-02 在独立后台标签页验证可返回：

- 当前门店名、地址、行政区、营业时间、分类；
- GCJ-02 经度、纬度；
- 高德原始评分、评价数、参考人均；
- 标签和图片引用。

正式网站不导入电话字段，原始响应保存在本地核验目录。图片地址只作核验引用。榜单页与详情页时间不同，必须保留两个快照日期；POI 可能改名、装修或出现临时关闭时间，不能因为同一 POI ID 就沿用旧名称和营业结论。

读取详情曾触发站点校验，随后由用户完成网页验证。恢复后先用正常门店页面确认，再通过既有浏览器登录态低频顺序读取，每条立即保存至 `research/raw/amap-poi-2026/`。不提取 Cookie、不伪造签名；再次遇验证码、登录或限流即停止。单店 `POI not found` 作为失效记录排除。该网页请求不是承诺稳定的开放平台榜单 API。

## 建议接入顺序

1. 从166个唯一 POI 中排除现有门店与明显重复分店，选择至少80个候选。
2. 按 POI ID 回读当前详情；名称、地址、营业时间、评分、人均、评价数和坐标各自保留采集日期。
3. 当前名称与2025榜单名称不一致、显示装修或临时关闭的门店转待核验。
4. 2026近180天回头客人数只从当前 App 回头客榜补充，不从2025榜单的全年综合分推算。
5. 只有高德官方榜单页证明上榜；普通 POI 详情只补充已确认上榜门店。
