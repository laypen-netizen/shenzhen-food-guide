# 高德接口核验（2026-10-02）

## App界面采集进展

已通过用户截图与 iPhone 镜像读取真实高德扫街榜门店，取消“十年老店”筛选后继续补充西餐、牛排、烤鱼、砂锅粥。门店数量以 `src/data/catalogue.json` 为准。回头客榜页面实际显示“近180天回头客”人数，已与门店详情的地址、评价数、人均及营业时段逐店对应；来源路径和本地截图均保存。CSV见 `research/amap-observed-shops.csv`，截图不打包至网站或默认上传。

店龄已经改为可选资料。回头客人数是页面原值，缺少完整口径与分母时不能称为回头率，也不直接换成综合评分。导航热度、本地推荐人数、菜品“多人多次品鉴”和平台收录年限均各自保留含义。榜单显示“附近”时会保留这一范围，不冒充深圳全市排名。当前采集是有限样本；按用户最新要求取消每区10家及总量配额，优先核验评分、评价数量、回头客与原范围榜单相互支持的商家。

## 公开接口

已实际读取官方概述、POI 2.0、旧版 POI 和 URI 文档。POI 2.0 文档标注最后更新 2026-07-15。

- [POI 2.0](https://lbs.amap.com/api/webservice/guide/api-advanced/newpoisearch)：`https://restapi.amap.com/v5/place/text`，必填 Web 服务 Key。`show_fields=business,photos` 可请求营业时间、电话、特色标签、rating、cost、图片链接，字段可能缺失。
- 普通搜索按高德搜索综合权重排序；没有文档支持将这个顺序称作“扫街榜排名”。文档明确同参数翻页最多200条，不支持全量返回。
- [Web服务概述](https://lbs.amap.com/api/webservice/summary)：已公开的 API 目录中未找到扫街榜专属接口。这是本次公开文档检索结论，不等于证明高德没有合作接口。
- [URI 搜索](https://lbs.amap.com/api/uri-api/guide/search/search)：`https://uri.amap.com/search` 支持 keyword、city、view、src、callnative，无需将 Web 服务 Key 交给网站访客。

尚未取得经过用户授权的 Web 服务 Key，因此没有真实调用 POI API，也没有确认账号权限、配额或实际字段覆盖率。照片 URL 并不单独证明复制/再发布权。取得数据后仍需审核使用条款、门店匹配、评分量表和图片授权。

接入采用本地离线采集 → 候选文件 → 人工证据审核 → 正式静态数据。采集器不写入正式数据，不请求私有移动端接口，不获取登录 Cookie 或 App 签名。

追加核验：

- [官方 MCP](https://lbs.amap.com/api/mcp-server) 页面标注更新于2026-03-17，列出关键词/周边/详情搜索、路径规划等，未列出扫街榜或回头客指标接口。
- [官方 CLI](https://lbs.amap.com/api/cli) 页面标注更新于2026-04-01，介绍 POI 搜索、地图容器和路线操作，未发现榜单数据能力；没有为此安装全局 CLI。
- 官方网页版 `www.amap.com/ssr/search` 实际查询“深圳 扫街榜 回头客”返回含“回头客”的店名，不是榜单。
- 官方网页版美食排序实际显示推荐排序、距离优先、好评优先、低价优先、高价优先，没有回头客/扫街榜排序。
- 实际读取一间官方门店详情，能够看到评分、评价数、价格、营业时间及用户评论，但没有榜单归属与具体门店开业证明。因此没有将它收入扫街榜目录。
- 公开搜索未找到深圳扫街榜的可读取高德短链接。不能据此断言分享链接不存在。

本次可用数据来自用户已授权的高德 App 界面读取，尚未取得扫街榜官方公开 API。普通 POI Key 不能替代榜单证据。用户要求多维综合评分，缺项不补造；已取消十年门店门槛，回头客人数独立展示。
